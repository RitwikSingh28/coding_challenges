# JSON Parser Challenge

This project is a JSON parser built as part of the [John Crickett Coding Challenges](https://codingchallenges.fyi/challenges/challenge-json-parser).

The goal is to build a functional JSON parser in Go that can handle various edge cases and validate JSON structure.

## Resources Currently Going through

- [Parsing (Wikipedia)](https://en.wikipedia.org/wiki/Parsing)
- [Lexical Analysis (Wikipedia)](https://en.wikipedia.org/wiki/Lexical_analysis)
- [Parsing JSON is a Minefield](https://seriot.ch/security/parsing_json.html)

### Recommended Learning
- [Writing An Interpreter In Go](https://compilerbook.com/) - Definitive Go-specific guide.
- [Crafting Interpreters](https://craftinginterpreters.com/) - Excellent conceptual overview of scanning and parsing.
- [Lisperator: How to implement a programming language](http://lisperator.net/pltut/) - Concise breakdown of the parser layers.
- [Let's Build A Simple Interpreter](https://ruslanspivak.com/lsbasi-part1/) - Visual, step-by-step blog series.

## Testing

This project utilizes the [JSONTestSuite](https://github.com/nst/JSONTestSuite) to ensure compliance with the JSON specification.
